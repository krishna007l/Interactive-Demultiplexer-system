LEARN THE CONCEPT

From input to output

A small building block with a big role in digital systems.

01

Introduction

A demultiplexer (DEMUX) is a combinational circuit that takes one data input and directs it to one of several outputs.

02

Objective

Understand how select lines choose the destination for a single digital input signal.

03

Problem statement

Demonstrate DEMUX operation interactively and show how input and select-line changes affect each output.

04

Processing / logic

Read the select lines as a binary index, set every output LOW, then route D to the indexed output.

05

Applications

Data routing, communication systems, digital circuits, and control systems.

06

Advantages

Simple routing, efficient signal distribution, and easy digital control using a small number of select lines.
